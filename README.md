# FashionInsightAI
FashionInsightAI is an AI-powered fashion analysis application that can identify clothing items, analyze colors and styles and provide outfit recommendations from uploaded images.

### Technologies Used
- Python
- Streamlit
- Pillow
- Google Gemini API
